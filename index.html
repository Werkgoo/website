Veelgestelde vragen

Alles wat je wil weten

Hoe snel is mijn website klaar? +
Gemiddeld leveren wij een website op binnen 5 tot 7 werkdagen na goedkeuring van het ontwerp. Heb je haast? Laat het ons weten, we kijken wat we voor je kunnen doen.
Wat heb ik nodig om te beginnen? +
Wij hebben jouw teksten, logo en eventuele foto's nodig. Heb je die niet? Geen probleem — wij helpen ook met teksten schrijven en zoeken passende stockfoto's voor je.
Kan ik mijn website later zelf aanpassen? +
Ja. Wij leveren je website met een eenvoudig systeem waarmee jij zelf teksten en afbeeldingen kunt aanpassen. Of je belt ons gewoon — kleine aanpassingen doen wij gratis in de eerste maand.
Zit mijn website goed in Google? +
Elke website die wij bouwen is standaard geoptimaliseerd voor zoekmachines (SEO). Je scoort dus beter in Google dan een website die daar niet op is ingericht.
Wat als ik niet tevreden ben? +
Wij werken met revisierondes zodat je altijd feedback kunt geven. We stoppen niet voordat jij 100% tevreden bent. Pas daarna gaat de website live.
